# 🚀 TechNews Today

### 🌐 Seu portal de notícias sobre o mundo da tecnologia

Um projeto web desenvolvido com **HTML5 e CSS3**, trazendo um visual moderno, organizado e responsivo para apresentar novidades do universo tecnológico.

---

## 💻 Sobre o projeto

O **TechNews Today** é uma página de notícias sobre tecnologia, criada para colocar em prática conceitos de desenvolvimento web e estilização de interfaces.

O site apresenta conteúdos informativos, vídeo integrado e uma área de inscrição para novidades.

## ✨ Recursos do site

- 🎨 Interface moderna com efeitos de transparência
- 🌈 Títulos com cores em degradê
- 📱 Layout responsivo para diferentes telas
- 📰 Área de notícias em destaque
- 🎬 Vídeo incorporado à página
- 📩 Formulário de inscrição
- 📌 Menu fixo durante a navegação

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura e organização da página |
| CSS3 | Estilização e efeitos visuais |
| CSS Grid | Organização dos conteúdos |
| Flexbox | Alinhamento dos elementos |
| Media Queries | Adaptação para diferentes telas |
